# Sprint Mission 06. SQL 음악 감상 데이터 분석

> 음악 서비스의 아티스트·앨범·곡·사용자·재생 기록 데이터를 SQL로 조회하여
> 2024년 음악 결산과 사용자별 감상 패턴을 분석한 미션입니다.

## Practice

* 여러 테이블을 `JOIN`하여 음악·사용자·재생 기록 결합
* 2024년 발매 앨범 및 활동 아티스트 조회
* 가장 많이 재생된 곡과 아티스트 집계
* 사용자별 인기곡·아티스트 분석
* 월별 음악 감상 횟수 및 총 재생 시간 계산
* 새롭게 발견한 아티스트 조회
* 사용자별 요일·시간대 재생 비율 분석
* 개인 감상 횟수와 전체 사용자 평균 비교

## Mentor Feedback

요구사항에 맞는 `JOIN`, 집계, 정렬 조건을 전반적으로 안정적으로 작성했다는 평가를 받았습니다.

다만 `DATETIME` 컬럼의 날짜 조건을 `LIKE '2024%'`로 처리한 부분은 정확성이 떨어질 수 있어, 이후에는 다음과 같이 명확한 기간 조건을 사용하는 것이 좋다는 피드백을 받았습니다.

`played_at >= '2024-01-01' AND played_at < '2025-01-01'`
