## Data Collection

### Cine21
- 박스오피스 Top10 기본 정보 수집
- 장르·등급·상영시간·국가·감독 정보 수집
- 전문가 별점 및 20자평 수집
- 총 42건의 전문가 리뷰 확보

### KOBIS
- 최근 14일 일별 박스오피스 Top10 수집
- 관객수·매출액·스크린 수·상영 횟수 수집
- 추가 분석을 위해 최근 1년 데이터까지 확장

---

## Analysis

다음 질문을 중심으로 분석했습니다.

1. 현재 박스오피스 상위 영화들은 어떤 작품 특성을 가지고 있는가?
2. 전문가 평점이 높은 영화일수록 실제 흥행 성과도 높은가?
3. 흥행 성과는 상영 기회와 관객 동원력 중 무엇과 더 관련이 있는가?
4. 박스오피스 관객수에는 요일에 따른 패턴이 나타나는가?

---

## Key Findings

- 상위 영화에서는 액션과 애니메이션 장르의 비중이 상대적으로 높게 나타남
- 분석 대상에서는 전문가 평점이 높을수록 흥행 성과도 높은 경향 확인
- 관객수와 스크린 수·상영 횟수 사이에 강한 양의 관계 확인
- 주말 평균 관객수는 평일보다 약 2배 높은 패턴 확인
- 최근 1년 데이터에서도 동일한 주말 효과가 반복적으로 나타남
- 전문가 20자평에 TF-IDF를 적용해 영화별 특징적인 평가 표현을 탐색

## Advanced Analysis

### Text Analysis
전문가 20자평에 형태소 분석과 불용어 제거를 적용하고,
키워드 빈도 및 TF-IDF 분석을 통해 영화별 특징적인 표현을 확인했습니다.

### Weekend Effect
최근 14일 분석에서 발견한 주말 관객 증가 패턴을
최근 1년 데이터로 확장하여 재검증했습니다.

Mann–Whitney U 검정을 통해 평일과 주말 관객수 분포의 차이를 확인하고,
효과크기까지 함께 검토했습니다.
