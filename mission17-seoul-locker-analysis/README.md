> 추가 설치 및 운영 개선이 필요한 지역을 진단한 클라우드 데이터 분석 미션입니다.

## Analysis Questions

1. 1인가구 수요에 비해 안심택배함 공급이 부족한 지역은 어디인가?
2. 공급이 부족하면서 실제 이용도 높은 지역은 어디인가?
3. 현재 이용 수준과 장기 이용 추세는 같은 방향을 보이는가?
4. 같은 자치구 안에서도 시설별 이용 성과에 차이가 존재하는가?
5. 이를 종합했을 때 증설·유지·운영 개선 중 어떤 대응이 필요한가?

---

## Key Findings

- 단순한 1인가구 규모보다 **시설당 1인가구 수**, 즉 수요 대비 공급 압력이 실제 이용 수준과 더 밀접하게 나타남
- 공급 부족만으로 증설 여부를 판단하지 않고 **공급 압력 × 현재 활용도**를 함께 고려해야 함
- 현재 이용량이 높더라도 장기 이용이 감소하는 지역은 즉시 증설보다 원인 점검이 우선
- 자치구 평균만으로는 내부의 고활용·저활용 시설 차이가 가려질 수 있어 시설 단위 진단이 필요
- 최종적으로 지역을 단순 순위가 아닌 **증설·유지·운영 점검·재검토 등 실행 방향**으로 분류
