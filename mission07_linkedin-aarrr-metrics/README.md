## Metric Design

LinkedIn을 하나의 사용자 흐름으로 보지 않고 사용자 목적에 따라 세 가지 관점으로 구분했습니다.

- **구직자** → 프로필 작성, 채용공고 탐색, 지원, 프리미엄 전환, 프로필 공유
- **실무자** → 프로필 업데이트, 네트워크 활동, 콘텐츠 반응, 유료 플랜 전환
- **기업 및 채용담당자** → 회사 페이지 생성, 채용공고 등록, 후보자 검색, InMail 발송, 유료 채용 솔루션 이용

각 AARRR 단계에서는 단순히 지표를 나열하지 않고  
**지표의 목적과 실제 측정 방식**까지 함께 정의했습니다.

---

## Key Metrics

- **Acquisition** → 회원가입 전환율, 유입 채널별 전환율, CAC
- **Activation** → 프로필 작성 완료율, 첫 핵심 행동 전환율
- **Retention** → 재방문율, 유지율, 고착도
- **Revenue** → 유료 구독 전환율, 고객당 평균 매출
- **Referral** → 추천 가입 전환율, 공유 및 확산 지표

---

## Mentor Feedback

일부 단계에서 가입자 수·공유 수·기업 수와 같은 **절대 수치**와  
회원가입 전환율·프로필 작성 완료율·초대 전환율과 같은 **비율 지표**가 함께 사용되었습니다.

향후에는 각 지표를

- 핵심 KPI로 활용할 비율 지표
- 서비스 규모를 확인하기 위한 절대 수치 지표

로 구분하여 역할을 명확히 정의하면 지표 체계를 더욱 정교하게 설계할 수 있다는 피드백을 받았습니다.
