# Sprint Mission 10. 멤버십 가격 A/B 테스트

> 멤버십 구독 페이지의 가격 표현 방식을 대상으로 A/B 테스트를 설계하고,  
> 매출 효과와 사용자 리스크를 함께 검증한 미션입니다.

---

## Project Summary

| 구분 | 내용 |
| --- | --- |
| 실험 목표 | 멤버십 구독 페이지 개선을 통한 매출 극대화 |
| A안 | 월간·연간 멤버십 가격 단순 비교 |
| B안 | 연간 멤버십의 1개월 환산 가격 강조 |
| 실험 대상 | 비구독 신규 유저 |
| 실험 기간 | 2026.01.15 ~ 2026.01.28 |
| 트래픽 배분 | A/B 50:50 |
| 성공 지표 | ARPU |
| 주요 분석 | Welch t-test, 비율 Z-test, 세그먼트 분석 |

## Metrics

### Success Metric
- **ARPU**: 방문자당 평균 매출

### Supporting Metrics
- ARPPU
- 전체 구독 전환율
- 연간·월간 구독 전환율
- Subscribe 버튼 클릭률
- 연간·월간 멤버십 버튼 클릭률

### Guardrail Metrics
- 구독 취소율
- 환불 문의율

---

## Key Findings

- ARPU는 A그룹 **56.82**, B그룹 **88.78**로 B안이 유의하게 높음
- 전체 구독 전환율은 A 36.02%, B 37.04%로 유의한 차이가 없음
- 연간 구독 전환율은 **17.07% → 29.27%**로 크게 증가
- 월간 구독 전환율은 **18.95% → 7.77%**로 감소
- B안은 전체 구독자를 크게 늘리기보다 유저의 선택을 **월간 → 연간 멤버십**으로 이동시켜 매출을 높인 것으로 해석
- 환불 문의율은 **1.96% → 4.42%**로 유의하게 증가하여 가격 표현에 따른 사용자 오해 가능성 확인

---

## Decision

B안은 ARPU와 연간 구독 전환율을 유의하게 높여  
매출 측면에서는 기존 A안보다 효과적인 것으로 나타났습니다.

다만 환불 문의율도 함께 증가했기 때문에 바로 전면 도입하기보다,

- 실제 연간 결제 금액
- 결제 주기
- 중도 환불 불가 조건

을 명확하게 안내하도록 가격 표현을 보완한 뒤  
조건부 도입 또는 후속 A/B 테스트를 진행하는 방향을 제안했습니다.

## Mentor Feedback

A/B 테스트 기획부터 데이터 전처리, 통계 검정, 결론 도출까지  
전체 분석 흐름과 성공·가드레일 지표를 사전에 정의한 프로세스를 긍정적으로 평가받았습니다.

추가 개선 방향으로는 다음 내용을 제안받았습니다.

- ARPU와 같은 매출 데이터의 비정규성을 고려해 Welch t-test 외의 검정 방법도 함께 검토
- 환불 문의 증가를 단순 리스크로 제시하는 데서 그치지 않고 구체적인 가드레일 방어책까지 연결
