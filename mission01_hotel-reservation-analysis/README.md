# Sprint Mission 01. 호텔 예약 이탈 분석

> 호텔 예약 및 고객 데이터를 활용해 취소·노쇼 고객의 특성을 분석하고,  
> 예약 이탈로 인한 손실을 줄이기 위한 운영 개선안을 제안한 Excel 분석 미션입니다.

---

## Project Summary

| 구분 | 내용 |
| --- | --- |
| 분석 주제 | 호텔 예약 취소 및 노쇼 분석 |
| 분석 도구 | Microsoft Excel |
| 주요 기능 | VLOOKUP, 피벗 테이블, 함수 및 계산식 |
| 분석 방식 | 그룹 내 정상 투숙·예약 이탈 비중 비교 |
| 주요 산출물 | Excel 분석 파일, 분석 보고서, 대시보드 |

예약 정보와 고객 정보를 `고객ID`를 기준으로 결합하고,  
예약 취소와 노쇼를 `예약 이탈`로 통합하여 어떤 조건에서 이탈 비중이 높아지는지 분석했습니다.

---

## Key Findings

- 전체 예약의 약 **31%가 예약 이탈**로 나타남
- 긴 예약 리드타임, 이전 취소 이력, 장기 숙박, 가족 유형 등에서 상대적으로 높은 이탈 비중 확인
- 보증금 유형과 일부 상품 조건에서도 큰 차이가 나타남
- 과거 방문 기록, 국적 권역 등은 단독 설명력이 낮게 나타남
- 하반기로 갈수록 예약 규모와 예상 손실액이 함께 증가

분석 결과를 종합하여 여러 위험 조건이 겹치는 예약을 **고위험 예약군**으로 정의했습니다.

---

## Recommendations

1. 보증금 정책 및 안내 방식 재점검
2. 장기 선예약 고객 대상 단계별 예약 확인
3. 이전 취소 이력 고객 별도 관리
4. 성수기 고위험 예약 집중 관리
5. 가족·장기 숙박·중고가 예약 맞춤 대응
6. 식사 포함 상품 및 패키지 전환 유도
7. 주요 위험 조건을 활용한 예약 이탈 관리 기준 마련
