\# Sprint Mission 01. 호텔 예약 이탈 분석



> 호텔 예약 및 고객 데이터를 활용해 취소·노쇼 고객의 특성을 분석하고,

> 예약 이탈로 인한 손실을 줄이기 위한 운영 개선안을 제안한 Excel 분석 미션입니다.



\## Project Overview



| 구분 | 내용 |

| --- | --- |

| 분석 주제 | 호텔 예약 취소 및 노쇼 분석 |

| 분석 도구 | Microsoft Excel |

| 주요 기능 | VLOOKUP, 함수 및 계산식, 피벗 테이블, 피벗 차트 |

| 분석 방식 | 그룹 내 정상 투숙·예약 이탈 비중 비교 |

| 주요 산출물 | Excel 분석 파일, 분석 보고서, 대시보드 |



호텔 예약 데이터와 고객 데이터를 `고객ID`를 기준으로 결합하여,

어떤 고객 및 예약 조건에서 실제 투숙으로 이어지지 않는 비중이 높아지는지 분석했습니다.



노쇼 건수가 적어 단독 분석 시 차이가 명확하지 않았기 때문에

예약 상태를 다음과 같이 재정의했습니다.



\- 정상 투숙: 체크아웃

\- 예약 이탈: 예약 취소 + 노쇼



\## Data Preprocessing



중복값, 결측값, 이상치 여부를 확인하고

원본 데이터와 전처리 데이터를 별도 시트로 관리했습니다.



분석을 위해 다음과 같은 파생변수를 생성했습니다.



`예약 이탈 여부` · `체크인 월` · `총 숙박 일수` · `총 숙박 인원` ·

`인원 구성 유형` · `방 일치 여부` · `국적 권역` · `예약 리드타임 구간` ·

`일평균 요금 구간` · `총 매출액` · `예상 손실액`



\## Key Findings



전체 예약의 약 \*\*69%는 정상 투숙\*\*, \*\*31%는 예약 이탈\*\*로 나타났습니다.



예약 이탈 비중 차이가 상대적으로 크게 나타난 조건은 다음과 같습니다.



\- 보증금 유형

\- 긴 예약 리드타임

\- 이전 취소 이력

\- 장기 숙박

\- 가족 단위 예약

\- 중고가 요금대

\- 시티 호텔

\- 식사 불포함 예약



반면 과거 방문 기록, 국적 권역, 방 일치 여부는

단독으로 예약 이탈을 설명하기에는 차이가 크지 않았습니다.



또한 하반기로 갈수록 예약 규모와 함께 예약 이탈 비중과 예상 손실액도 증가했으며,

특히 연말에는 매출 규모와 손실 위험이 동시에 높게 나타났습니다.



\## Business Recommendations



분석 결과를 바탕으로 다음과 같은 운영 개선안을 제안했습니다.



1\. 보증금 정책 적용 방식과 안내 문구 재점검

2\. 장기 선예약 고객 대상 단계별 예약 확정 프로세스 운영

3\. 이전 취소 이력 고객에 대한 별도 확인 절차 적용

4\. 성수기 고위험 예약군 집중 관리

5\. 가족·장기 숙박·중고가 예약별 맞춤 대응

6\. 식사 포함 상품 및 패키지 전환 유도

7\. 주요 위험 조건을 조합한 예약 이탈 관리 기준 마련

본 미션은 Excel을 활용한 탐색적 분석을 중심으로 진행했기 때문에

관찰된 차이의 통계적 유의성이나 인과관계를 직접 검증하지는 않았습니다.

각 변수와 예약 이탈 간의 관계를 보다 정교하게 검토할 수 있습니다.
