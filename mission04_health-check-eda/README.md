## Data Preprocessing

변수의 특성을 고려하여 결측값과 이상치를 서로 다른 기준으로 처리했습니다.

- 범주형 변수 → 최빈값 대체
- 허리둘레·혈압·혈당 → 성별·연령대별 중앙값 대체
- 시력 → 실명 코드 `9.9`를 제외한 중앙값 대체
- 이상치 → IQR 기준만 적용하지 않고 건강지표의 의미와 실제 관측 가능성을 함께 고려

특히 통계적 이상치라는 이유만으로 값을 일괄 제거하지 않고,  
의학적 기준과 데이터 분포를 함께 확인하여 실제 오류 가능성이 높은 극단값만 선별했습니다.

---

## Key Findings

- 남성은 30~40대 전후에서 평균 BMI가 높고, 여성은 연령 증가에 따라 BMI가 높아지는 경향 확인
- BMI가 증가할수록 평균 혈압도 함께 높아지는 패턴 확인
- BMI가 높아질수록 정상 혈당 비율은 감소하고 공복혈당장애·당뇨의심 비율은 증가
- 고혈압 위험은 전반적으로 연령이 증가할수록 상승
- 흡연 상태 등 생활습관에 따라 건강위험 비율 차이가 나타났으나 인과관계로 단정하지 않고 해석

건강위험은 하나의 변수보다 **연령·성별·비만도·생활습관이 함께 작용하는 구조**로 해석했습니다.
