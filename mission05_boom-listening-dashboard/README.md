# Sprint Mission 05. 음악 스트리밍 사용자 유형 분석

> 가상의 음악 스트리밍 서비스 BOOM 이용 데이터를 Tableau로 시각화하고,
> 청취 행동에 따라 사용자를 세분화하여 유형별 타기팅 전략을 제안한 미션입니다.

## Key Findings

* 사용자를 청취 행동에 따라 **4개 유형**으로 세분화
* 성별보다 **연령대가 유형 간 차이를 설명하는 주요 변수**로 확인
* 금요일을 중심으로 청취가 증가하지만 유형별 집중 시점에는 차이가 존재
* 비·눈 등 날씨 조건에 따라 특정 청취 행동이 강화되는 패턴 확인
* 유형 × 연령 × 요일 × 날씨를 함께 고려하여 타기팅 전략 수립

### Targeting Strategy

* **차트 집중형** → 10~20대 중심, 금요일 차트 노출 강화
* **추억 반복형** → 재청취 및 리텐션 중심 전략
* **직접 탐색형** → 검색 및 탐색 기능 개선
* **유행 추종형** → 신곡·화제곡 중심의 단기 집중 캠페인

---

## Mentor Feedback

* 사용자를 4개 청취 유형으로 세분화하고 동일한 기준으로 비교한 분석 구조
* 유형·시간·환경 조건을 교차하여 행동 차이를 해석한 점
* 성별이 유형을 설명하는 핵심 기준이 아니라는 결과를 전략에 반영한 점을 긍정적으로 평가받았습니다.
